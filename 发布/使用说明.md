# 行车记录仪视频调正工具 · 使用说明

一个用 Rust 编写的本地视频调正工具：把镜头翻转导致的**上下颠倒 180°** 视频转正，并对夜间噪点做**轻度降噪**（保住车牌、路牌、仪表等关键细节）。

**全 GPU 管线（自动检测）**：解码、降噪、翻转、编码全部在 NVIDIA 显卡上运行，**CPU 占用约 2~5%（几乎全闲，留给其他软件）**，GPU 计算引擎接近满载。所有子进程以低优先级运行，前台软件始终优先。

## 目录内容

```
video-fixer.exe        图形界面版（双击运行）
video-fixer-cli.exe    命令行版（批量/自动化用）
bin\ffmpeg.exe         转码引擎（必须与本程序放在一起）
bin\ffprobe.exe        探测工具
使用说明.md            本文件
```

> 以后换新电脑复用：把整个文件夹拷走即可（ffmpeg 已内置，无需安装任何东西）。

## 快速开始（图形界面）

1. 双击 `video-fixer.exe`。
2. 选择**输入目录**（如 `D:\摩托行车记录仪视频存档\261018`）——会自动扫描（含子目录），文件列表带缩略图，**颠倒的视频一眼就能看出来**。
3. 选择**输出目录**（默认在输入目录下建"调正输出"子文件夹；原文件完全不动）。
4. 确认参数（默认即可）：
   - 转向：`180° 上下颠倒`
   - 降噪：`轻度（保细节）`
   - 勾选"跳过已完成"：重复运行时自动跳过已转好的文件，支持中断续跑
5. 点击 **▶ 开始处理**（窗口左下角）。每个文件实时显示进度和速度，"取消"可随时中断（中断不会损坏文件，输出写的是临时 `.part` 文件，成功后才改名）。
6. 全部完成后抽查几集效果，确认无误后可自行删除旧文件夹。

## 命令行版

```
video-fixer-cli.exe <输入目录> [输出目录] [--angle 180|90cw|90ccw|hflip|vflip] [--denoise off|light|medium] [--threads N] [--jobs 1~4] [--size 10~100] [--hevc] [--overwrite] [--flat]
```

例：`video-fixer-cli.exe D:\摩托行车记录仪视频存档\261018 D:\调正完成`
默认 180° + 轻度降噪 + 跳过已存在。

## 压缩体积

设置行新增两个选项（对调正/降噪功能无影响，只改变输出体积）：

- **"输出体积"下拉**：与原片相当（默认）/ 压缩约 30% / 压缩约 50% / 压缩约 70%。按原片码率等比压缩，压缩模式下自动启用更高效的 p5 预设与自适应量化（AQ）。
- **"编码格式"下拉**：H.264（默认，兼容性最好）/ H.265/HEVC——同画质体积再省 30% 左右（软件会自动把 HEVC 的码率再降 30%）。现代播放器/手机/电视基本都支持 HEVC，老设备可能不认。
- **压缩空间来自降噪**：夜间噪点正是吃码率的大户，降噪后 50% 体积的画质损失非常小（实测夜间车牌、路牌、仪表文字依然清晰）。列表标题栏会显示预计体积。
- CLI 对应参数：`--size 50`（百分比）、`--hevc`。

组合建议：压缩约 50% + H.265 约为原片体积的 35%，70GB 存档可压到 25GB 左右，日常回看画质足够。

## 性能与资源说明

- **处理效果实测**：2560×1440 30fps 行车记录仪视频，单路约 1.1 倍实时速度（5 分钟视频约 4 分半转完）；降噪采用非局部均值算法（NLMeans），夜间画面噪点明显减少，路牌、仪表文字保持清晰。
- **全 GPU 管线（默认）**：开启降噪时，单路即可把 GPU 计算引擎用到 ~100%（这正是"活都交给显卡"的效果），此时自动模式保持 1 路；**CPU 仅占用约 2~5%**。
- **想要更快**：把降噪设为"关闭"→ GPU 有富余，自动模式会开多路并行，速度可达 3 倍以上，CPU 依然很低（但没有降噪）。
- **"CPU 总线程预算"滑块**：所有并行任务共享的 CPU 上限（自动按并发分摊），全 GPU 管线下 CPU 本就接近空闲，此滑块主要用于无 Vulkan 的回退模式。
- **显存**：开启降噪时处理显存约 2~3GB。如需边玩游戏边处理，建议把降噪设为"关闭"（显存占用更低、速度更快），或等游戏结束后再跑。

## 常见问题

- **提示"未找到 ffmpeg"**：确认 `bin\ffmpeg.exe` 与 `bin\ffprobe.exe` 和本程序在同一个文件夹。
- **NVENC 不可用**：需要 NVIDIA 显卡驱动较新（本机驱动 560.94 已验证可用）。若换用无 NVIDIA 显卡的机器，软件会自动回退软件编码（速度变慢，仍可用）。
- **界面显示"CPU 轻量翻转/降噪"**：说明当前环境的 Vulkan 链路不可用，软件已自动回退；此时 CPU 占用会高一些，可用"CPU 总线程预算"滑块限制。
- **画面方向不是 180°**：界面上切换"转向"为 90° 或镜像后再处理；缩略图会跟随设置变化，方便确认。
- **想跳过某些视频**：取消勾选列表中的文件即可。
- **降噪强度**：默认"轻度"对细节影响很小；夜间噪点特别重时可试"中度"。"关闭"则完全不降噪（纯调正，速度最快）。

## 技术细节（供参考）

- **全 GPU 管线**：Vulkan Video 硬解 → nlmeans_vulkan 非局部均值降噪 → transpose_vulkan 翻转 → 数据回内存（驱动 DMA）→ NVENC 编码（按源片 H.264/H.265 自动选择编码器，码率匹配源片）。
- 启动时自动探测 Vulkan 链路可用性（用合成视频实测解码/降噪/翻转整条链），不可用时逐级回退：CUDA 翻转 → CPU 轻量翻转/降噪（均有限线程 + 低优先级）。
- 动态并发：每 5 秒采样 GPU 占用率自动增减并行路数（降噪开时 GPU 已满则保持 1 路；降噪关时 GPU 有富余则自动多路）。
- ffmpeg 子进程以 BELOW_NORMAL 优先级运行，保证前台软件流畅。
